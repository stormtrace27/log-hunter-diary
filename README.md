# log-hunter-diary

Hunting through logs, packets and alerts: my journey to becoming a SOC analyst. Labs, notes and write-ups.

## About me

I'm Dhrity, an IT student building toward an entry-level SOC analyst role. I'm a beginner, and this repo is where I learn in public: every lab gets a short note, and every project gets a proper write-up.

All practice is done on labs and VMs I own or am authorised to use.

## How I write my notes

Each note is short and in my own words:

1. What I studied and the date
2. The goal in one sentence
3. Commands or tools I learned, and what each does
4. One mistake I made
5. One lesson, and how a SOC analyst would use it

I don't copy platform content or post answers to challenges. I describe the method and what I learned.
